## 与任务上下文的差异（以本提示词与契约为准）
1. **你不碰 `touch.js`**。任务 4 上下文里提到的“镜镜像右键、开火置 `mouse.lp`”是**既有按钮**的行为变更，归 L3b，不归你。你只实现**新增**按钮：`menu board loadout inspect slot1 slot2 slot3 slot4`。
2. **你也不改 `catalogs.js`**：所需键（`touch.menu/board/loadout/inspect`）已经加好。
3. 你通过契约 §2 的 `touch` API 工作：`touch.addButton({ act, label | labelKey, down, up, cancel })`、`touch.requestPause('menu')`、`touch.player()`、`touch.isPlaying()`。**不要**自己调用 `game.pause()`（`requestPause` 已含守卫与状态清零）。
4. 按钮位置由 `layout.items[act]` 决定，`touch.js` 负责定位；你不写坐标，只可在 `menu` CSS 分区里写字号、圆角、颜色等外观（选择器以 `html.is-touch` 开头，例如 `html.is-touch #touch .btn[data-act="board"]`）。小按钮（44px）里文字要能放下：`INSPECT` 等较长英文用较小字号并 `overflow:hidden`。

## 行为（契约 §4 为准）
- `menu`：固定文本 `☰`，`aria-label` 取 `touch.labelText('touch.menu')`；按下调用 `touch.requestPause('menu')`。
- `board`：**切换**。开 → `player.keys.add('Tab')`，关 → `player.keys.delete('Tab')`；用 `game.paused / game.ended` 变化时自动关（可用 `touch.onLayout` 之外的方式：在每次按压与 `requestPause` 后检查；若确实需要周期性检查，用不超过 250ms 的 `setInterval` 并在 `detach` 清除，且不得在暂停外持续做 DOM 写入）。
- `loadout` → `player.pressed.add('KeyB')`；`inspect` → `player.pressed.add('KeyF')`；`slot1..4` → `player.pressed.add('Digit1'..'Digit4')`。
- 所有按钮点击都被 `touch.isPlaying()` 守卫：不在对局中（大厅/结算/暂停）不产生输入。
- `player` 为空（`touch.player()` 返回 null）时不抛错。
- `detach` 幂等：清除计时器、订阅，并释放 `Tab`。
