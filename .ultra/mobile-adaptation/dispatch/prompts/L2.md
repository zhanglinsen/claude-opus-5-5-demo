## 怎么写
- 复用 `helpers/touch-dom.mjs`（已提供一站式构造 `TouchControls`、`byAct`、`byText`、`fireWindow`、`fireOn` 等；先读它的导出与用法，**不要修改它**，需要扩展就在你自己的测试文件里写局部辅助函数）和 `helpers/fake-env.mjs`。
- 这是**端到端**测试：通过 `new TouchControls(game)`（`cf-transport-ship/src/touch.js`）工作，用 `[data-act="…"]` 找按钮（契约 §4），不要 import `src/mobile/*.js` 里的模块。
- 用例 6：`menu` 按钮仅在 `playing && !paused && !ended` 时使 `game.pause()` 被调用一次；不在对局中不调用；`adPaused` 时不调用。
- 用例 7：`board` 切换增删 `player.keys` 的 `Tab`；`loadout/inspect/slot1..4` 分别注入 `KeyB/KeyF/Digit1..4` 到 `player.pressed`；不在对局中不产生输入。
- 用例 9：`document` 的 `visibilitychange`（`env.setHidden(true)`）与 `window` 的 `pagehide`：清触屏状态 + 只暂停一次 + `game.audio.ctx.suspend` 被调用；`adPaused` / 已暂停 / `playing=false` / `ended=true` 的边界。
- 用例 10：`env.setViewport(390, 844)` 变为竖屏且对局中：暂停一次并出现 `#rotateGuard`（`document.body` 的子节点，`id === 'rotateGuard'`）；非对局不触发。
