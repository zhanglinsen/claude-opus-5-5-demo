## 同机实测

环境：AMD Radeon Pro 5500M（ANGLE Metal），1920×1080，中画质，headed Chrome；机器负载 load1 4～21 波动，已如实记录。

### 1. FPS 配对（`accept-gpu-pair.mjs`，`artifacts/perf-20260929-pair.json`）

运输船：基线中位 16/15，候选 13/13。经典沙漠：基线 17/19，候选 19/18。

**不可比**：出生点随机、玩家静止，两边截图机位和画面不同；整机 13～19 FPS，瓶颈在 GPU，由画面内容主导。不作回归或提升结论。

### 2. 固定种子的 CPU 帧耗时（`artifacts/cpu-pair.json`，每图 3 轮交替，每轮 30 秒）

每帧 CPU 耗时，单位 ms，取 3 轮中位：

| 地图 | 指标 | 基线 P50/P95 | 候选 P50/P95 |
|---|---|---|---|
| 运输船 | renderFrame（含 HUD、特效） | 3.8 / 5.1 | 3.3 / 4.3 |
| 运输船 | updateHUD | 0.6 / 0.9 | 0.2 / 0.5 |
| 运输船 | simulate（含 AI 射线） | 1.9 / 5.9 | 1.9 / 5.8 |
| 经典沙漠 | renderFrame | 3.0 / 4.0 | 2.3 / 3.1 |
| 经典沙漠 | updateHUD | 0.7 / 1.0 | 0.2 / 0.4 |
| 经典沙漠 | simulate | 0.5 / 2.2 | 0.5 / 2.4 |

- 每帧 CPU 约省 0.5～0.7ms，主要来自 HUD，其次是特效。
- simulate 无可测变化：射线开销在整帧里占比很小，微基准的收益在这里被噪声淹没。
- 帧间隔 P50 为 50～100ms（10～20 FPS），CPU 节省不到帧时间的 1%。**本机 FPS 预计无可测提升**，瓶颈在 GPU。

## 结论与下一轮

- 本轮 CPU 优化有实测收益，未发现正确性回归，也未发现 CPU 回归。
- 本机低 FPS 的主因在 GPU。按计划"后续按证据决定"，下一轮应先对 draw calls、透明过绘、阴影更新做采样分析，再分工。
